# 測点サーチPro

LandXMLの路線を読み込み、メインA路線の測点から直角な横断線を引き、他路線の測点を計算するブラウザーアプリです。今回の納品はユーザー指定により**ローカル版**です。

## 起動

このフォルダーの **起動.cmd** をダブルクリックしてください。開発サーバーとブラウザーが起動します。コマンドで起動する場合は次の手順です。

```powershell
cd C:\Users\maooh\Documents\アプリ開発\route-station-link
npm ci
npm run dev
```

アクセス先は http://127.0.0.1:5192/ です。起動したターミナルを閉じるとサーバーが停止します。Node.js 24で動作確認しました。地図タイルの取得にはインターネット接続が必要です。

## 使い方

1. 案件名・平面直角座標系・標高基準を設定します。XMLに座標系がある場合は最初のファイルから自動設定します。
2. 「LandXMLを追加」で複数選択、または画面へ複数ファイルをドロップします。
3. 左の路線一覧でメインA路線を選びます。
4. 「測点を追加」で地図上をクリックするか、「測点 SP」に路線の累加距離を入力して「数値で追加」を押します。クリック位置はA路線の最寄り位置へ合わせます。
5. ピンをドラッグ、または右パネルの測点数値を編集すると、他路線の結果が追従します。数値編集は入力欄からフォーカスを外すと反映します。
6. 右パネルで高さHとコメントを入力します。複数の交点候補がある場合は候補を選択します。
7. 「Excel出力」で現在のメインA路線のピンと対応路線の結果を出力します。

Excelは「路線」「測点」「高さ」「コメント」の4列、全セルがMeiryo 12ptです。高さは数値・表示小数3桁、未入力は空欄です。他路線へAの高さ・コメントをコピーしません。交点なしは明示し、候補未確定・線の重複時は確定まで出力を止めます。

案件はこのブラウザーへ自動保存します。「案件を保存」「案件を開く」でJSONファイルへの保存・復元もできます。

## マウス操作

| 操作 | 2D | 3D |
|---|---|---|
| 左クリック | 路線・ピン選択／追加モード時に追加 | 同左 |
| 左ドラッグ | Aピンを移動 | Aピンを基準面で移動 |
| 右クリック | 回転中心を設定（表示位置は維持） | その位置に回転中心を設定。カメラは移動しない |
| 右ドラッグ | 押した位置を中心に左右ドラッグで回転 | 回転中心を軸に回転 |
| ホイールドラッグ | 平行移動 | 平行移動 |
| ホイールを奥へ | 拡大 | 拡大 |
| ホイールを手前へ | 縮小 | 縮小 |
| Ctrl＋ホイール | 低速ズーム | 低速ズーム |

3D回転速度は標準0.2倍・Alt 0.5倍・Shift 1倍です。両方押した場合はShiftを優先します。カメラの慣性・減衰・イージングはありません。

## 対応範囲と制約

- 水平線形の `Line` と `Curve`（直線・円曲線）に対応します。提供されたSiTECH3DのXML2件は読み込み・計算・表示を確認しました。
- `Spiral`、`StaEquation` は未対応として明示的に拒否します。誤った直線へ置換したり、無視して誤測点を出したりしません。
- 長さ単位meter、JGD2000/JGD2011/JGD2024、第1～19系に対応します。日本の平面直角座標はXMLの「北方向X・東方向Y」を内部の「E・N」へ対応させています。測地系・系番号の異なる路線を無変換で混在させません。
- 測点はSP（累加距離）表記です。No.間隔設定、クロソイド、詳細CSV出力は今回の実装に含めません。
- 横断線の片側範囲は初期500mです。「表示と計算の設定」で1～10,000mに変更できます。路線端を延長して計算することはありません。
- **3Dの路線はH=0の基準面上へ表示し、手入力したピン高さを反映します。XMLの縦断Profile・ParaCurveから道路の標高を復元する機能はありません。**
- ファイルは1件30MBまでです。解析はWeb Workerで行います。測点交点の再計算はブラウザーのメインスレッド上で行うため、大量路線・大量ピンの性能上限は未測定です。
- LandXML原本を上書きしません。XML・コメントをWebサーバーへ送信しません。背景タイルは外部配信元へリクエストします。

## 地図

通常地図はOpenStreetMapです。国土地理院の地図タイルを使用していません。

背景はOpenStreetMapの通常地図のみです。航空写真の切り替え・APIキー入力・配信接続は削除しました。

参考資料（2026-09-21確認）：[座標系原点・軸の定義](https://vldb.gsi.go.jp/sokuchi/surveycalc/surveycalc/jpc/jpc.htm)。座標定義の確認に国土地理院の資料を使用していますが、背景地図は別配信元です。

## Excel出力の列構成
1行目は「測点名／A路線の実名／他路線の実名…／高さ／コメント」です。A測点ごとに1行、路線ごとの対応SPを横に出力します。測点名にはA路線のSPを使用。高さ・コメントはA測点の入力値です。路線数に応じて末尾列を移動し、メイリオ12pt・高さの数値形式を維持します。

## LandXML追加（2026-09-22修正）
合計10ファイルまで追加できます。同名・別内容のファイルを許可し、SHA-256で同じ内容の重複を防ぎます。複数路線のXMLも1ファイルとして数えます。旧保存データはファイル名で既存ファイル数を数え、内容ハッシュがない旧データとの重複判定はできません。
